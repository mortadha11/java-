# Zoo Management Application

## Description
Cette application Java permet de gérer un zoo de manière simple et structurée. Elle inclut la gestion des animaux terrestres et aquatiques avec leurs caractéristiques et comportements spécifiques. L'application est conçue pour démontrer les concepts de **programmation orientée objet** tels que l’héritage, l’encapsulation et la modularité.

---

## Fonctionnalités
- Ajouter et gérer différents types d'animaux (terrestres et aquatiques).  
- Visualiser les informations sur chaque animal :  
  - Nom  
  - Espèce  
  - Âge  
  - Habitat  
  - Caractéristiques spécifiques (ex : nage pour les aquatiques)  
- Exemple de classe abstraite `Animal` et ses sous-classes `Aquatic` et `Terrestrial`.  
- Validation des données lors de la création des animaux.  

---
